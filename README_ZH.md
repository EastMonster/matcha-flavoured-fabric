# Matcha Flavoured Fabric

> [!WARNING]
> 此非官方 Fabric 移植版的核心内容已经过测试，但部分边缘情况可能与原数据包不同。游玩前请备份存档。

[English](README.md)

这是 Klei Wright 制作的 [**Matcha Flavoured**](https://modrinth.com/datapack/matcha-flavoured) 数据包与资源包的非官方 Fabric mod 移植版，适用于 Minecraft 26.2。

制作这个移植版的主要原因，是我个人不太喜欢数据包通过大幅修改原版物品来充当新物品的实现方式。这种方式与 JEI 结合使用时也不够方便。因此，Fabric 版把装备、食物、鱼、祝福、唱片及大部分其他自定义内容注册成了真正独立的 mod 物品。

## 环境要求

- Minecraft 26.2
- Fabric Loader 0.19.3 或更高版本
- Fabric API 0.156.0+26.2 或更高版本
- Java 25

## 安装

安装 Fabric Loader 和 Fabric API，然后把本 mod 的 JAR 文件放入 `mods` 文件夹。

建议尽量使用新世界。数据包版本中基于原版物品制作的已有物品，不会自动转换为本 mod 独立注册的物品。

## 对数据包的改进

- 不再把原版物品魔改成新物品，而是在 `matcha-flavoured` 命名空间下独立注册装备、食物、鱼、祝福、行为物品和唱片等大部分内容。新增内容因此在物品栏及 JEI、Jade 等工具中更容易识别和查找；物品 ID 和指令与数据包版不同，**已有的数据包版物品也不会自动转换**。已按用途把注册物品放入对应的原版创造模式标签页。
- 食物回血改为按每次食用独立计时，不再依赖数据包使用的再生效果。原版再生同效果刷新不会叠加持续时间，连续吃同一种食物会静默丢失部分回血；现在每个食物隐藏的“回血模拟”段各自独立计时，连续食用能回满预期血量。
- 树叶和发光地衣的破坏纹理不再延伸到空气中；树冠内部的树叶外延模型会被剔除，以减少渲染面数，同时保持树冠实心的观感。
- Mod Menu 设置页面可以让每位客户端玩家单独关闭主世界的 True Darkness，不会改变服务器玩法。
- 添加了 AI 辅助翻译的简体中文语言文件。

## 可能导致行为差异的修改

- 将依赖命令的玩法机制改写为 Java。已经测试的主要玩法以对齐数据包为目标，但极短时间窗口、多人目标选择，以及延迟动作期间重启服务器等边缘情况仍可能不同。
- 食物的隐藏回血模拟仅保存在当前服务器会话中；若在回血尚未完成时退出单人世界或停止服务器，剩余的隐藏回血不会继续。正常施加的状态效果仍由原版保存。
- 风刃使用玩家内部的 20 tick 冷却，不再借用数据包作为计时器的可见“霉运”效果；牛奶和净化也无法重置该冷却。
- 为部分原版食物载体设置了 Matcha 默认组件，使创造栏和普通 `/give` 得到的物品与合成或掉落版本一致。其他来源生成这些原版 ID 的无组件物品时，也可能因此获得 Matcha 食物行为。
- 欢乐恶魂号角会选择 80 格内最近的欢乐恶魂；原数据包的 `@e[limit=1]` 会任意选择一个匹配实体。选择最近目标是有意行为。
- `endless_repairs` 兼容机制还会清除盔甲栏和副手物品的铁砧先前工作惩罚；原数据包只扫描主背包和快捷栏。在免费铁砧规则下，这项差异通常没有实际影响。

欢迎反馈 Bug，但本项目不承诺与原数据包的所有边缘情况一比一完全兼容。
